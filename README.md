## CampusConnect (Programming 512 Assignment)

CampusConnect is a Python application for managing resource bookings at Richfield campuses. It includes Centurion, Bryanston, Pretoria and Capetown campuses. Lecturers can book resources, campus administrators can manage resources and view campus bookings, while the System Operator can view information across the different campuses.

# How to run
1. Make sure all files are in the same folder (main.py, classes.py, database.py and gui.py)
2. Run main.py (not the other files)

# Setup
When the application starts for the first time, create the system operator and campus administrator accounts on the setup screen. Lecturers can register from the login window.

# Requirements
* Python
* Tkinter (for the gui)
* SQLite (for the database (included in Python))

# Files
* main.py: starts the application
* classes.py: contains the classes and campus booking rules.
* database.py: stores and manages data in the database.
* gui.py: contains the graphical user interface (GUI).
